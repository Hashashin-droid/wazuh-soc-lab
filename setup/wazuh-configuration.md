
### Introduction

Security Information and Event Management (SIEM) platforms play a critical role in modern Security Operations Centers (SOCs) by collecting, aggregating, and analyzing security events from multiple sources.

For this lab environment, Wazuh was selected as the primary SIEM platform due to its open-source nature, extensive security monitoring capabilities, and ease of deployment.

The Wazuh server acts as the central monitoring platform responsible for collecting and correlating events from Windows endpoints, Linux systems, network security devices, and threat intelligence integrations.

### Overview of Wazuh

Wazuh is an open-source SIEM and XDR platform that provides:

- Threat detection
- Log management
- File Integrity Monitoring (FIM)
- Security Configuration Assessment (SCA)
- Vulnerability detection
- Incident response capabilities
- Compliance reporting

While there are many SIEM products available (e.g., `Splunk`, `IBM QRadar`, `Microsoft Sentinel`) , Wazuh is highlighted here due to its open-source nature and ease of deployment. These benefits make it an attractive choice for organizations seeking a cost-effective and customizable solution to enhance their security operations.

### Wazuh Architecture

The Wazuh architecture consists of the following core components :

**1. Wazuh Agent** 

The Wazuh Agent is installed on monitored endpoints and is responsible for :

- Collecting security events
- Monitoring files and directories
- Forwarding logs to the Wazuh Server through an encrypted and authenticated channel

**2. Wazuh Server**

The Wazuh Server is the central component responsible for :

- Analyzing data collected from Wazuh agents
- Detects threats, anomalies, and regulatory compliance violations in real time
- Generating alerts when suspicious activity is identifed

**3. Wazuh Indexer**

The Wazuh Indexer stores and indexes security events generated by the Wazuh Server and provides near real-time data search and analytics capabilities

**4. Wazuh Dashboard**

The Wazuh dashboard is a flexible and intuitive web interface for visualizing, analyzing, and managing security data

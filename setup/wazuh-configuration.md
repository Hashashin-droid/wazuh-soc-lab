
# Wazuh Configuration Guide

## Introduction

A Security Information and Event Management (SIEM) platform is used to collect, centralize, and analyze security logs from multiple sources.

For this lab, Wazuh was chosen as the primary SIEM platform because it is open-source, feature-rich, and easy to deploy in a home lab environment.

The Wazuh server acts as the central monitoring platform, collecting and analyzing events generated by monitored endpoints.

---

# Overview of Wazuh

Wazuh is an open-source SIEM and XDR platform that provides:

* Threat detection
* Log management
* File Integrity Monitoring (FIM)
* Security Configuration Assessment (SCA)
* Vulnerability detection
* Incident response capabilities
* Compliance reporting

Compared to commercial SIEM solutions such as Splunk, QRadar, and Microsoft Sentinel, Wazuh provides many core security monitoring features without licensing costs, making it a popular choice for learning and lab environments.

---

# Wazuh Architecture

The Wazuh platform consists of four main components.

## 1. Wazuh Agent

The Wazuh Agent is installed on monitored endpoints and is responsible for:

* Collecting security events
* Monitoring files and directories
* Forwarding logs to the Wazuh Server

## 2. Wazuh Server

The Wazuh Server is the central component responsible for:

* Receiving logs from agents
* Analyzing security events
* Detecting suspicious activity
* Generating security alerts

## 3. Wazuh Indexer

The Wazuh Indexer stores and indexes security events generated by the Wazuh Server, enabling fast searching and visualization.

## 4. Wazuh Dashboard

The Wazuh Dashboard provides a web interface for:

* Viewing alerts
* Investigating events
* Monitoring agents
* Searching logs

## Step 1: Download the Wazuh OVA

Download the official Wazuh OVA from:

https://documentation.wazuh.com/current/deployment-options/virtual-machine/virtual-machine.html

The OVA image includes:

* Wazuh Server
* Wazuh Indexer
* Wazuh Dashboard

This simplifies deployment because all major components are preconfigured.


Access the dashboard using:


Default credentials:

